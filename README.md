# ASW Smart Freight

智能海运报价系统双角色演示版：同一个网址提供客户入口和管理员入口。项目采用 Vue 3、Vite 与 Element Plus，业务数据为前端 Mock，无需后端服务即可演示。

## 已实现

- 统一入口：客户免登录使用；管理员使用演示账号登录
- 写实海运入口：全屏海面货轮视频、静音循环、暂停 / 恢复、静态封面、手机布局；尊重系统减少动态偏好，离开入口或切换到后台时暂停播放
- 客户端：智能询价、方案比较与排序、选择方案、生成报价单、查看记录及打印 / 另存 PDF
- 管理端：数据工作台、演示合同上传与核对、有效期管理、账号与权限展示、报价规则、操作记录
- 演示运价支持上海→洛杉矶、宁波→长滩、深圳→汉堡三条航线；柜型、日期、报价偏好和管理员规则会影响结果
- 数据保存在当前浏览器的 `localStorage` 中，刷新后仍可查看；换设备或清除浏览器数据后不会同步

## 演示账号与边界

管理员演示账号：`demo`，密码：`ASW2026`。账号和密码写在前端代码中，仅用于展示登录流程，**没有真实安全隔离**。账号管理页新增的用户只展示在列表中，不具备实际登录能力。不要上传真实合同或输入真实客户敏感信息，也不要把本版当作正式报价系统使用。

合同上传和解析是模拟操作，不读取真实文件。报价与船期也均为模拟数据；打印功能调用浏览器打印窗口，可选“另存为 PDF”。

## 本地运行

需要 Node.js 20.19+ 或 22.12+。

```bash
npm install
npm run dev
```

浏览器访问终端中显示的本地地址（通常为 `http://localhost:5173`）。

如果浏览器提示 `ERR_CONNECTION_REFUSED`，说明开发服务器未启动。请保持运行 `npm run dev` 的终端窗口打开，然后刷新页面。

在限制 Node 启动子进程的 Windows 环境里，如果 Vite 启动时报 `spawn EPERM`，可以用静态预览方式：

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/build-preview.ps1
node scripts/serve-preview.mjs
```

第二个命令需要持续运行；关闭终端后网页就无法访问。这份预览由相同的 Vue 源码生成，适合现场演示。

## 服务器演示部署

本项目当前为纯前端演示版，可将 `dist/` 作为静态网站放到 Nginx；无需在服务器上常驻运行 Vite。`deploy/nginx.conf.example` 提供基础配置模板。部署前需按实际服务器的域名或公网 IP、操作系统和已有 Web 服务调整配置，并开放相应的 HTTP/HTTPS 入口。当前页面与报价数据均为公开可见的 Mock，勿将真实客户合同放进前端源码。

本次双角色构建包为 `asw-price-dual-role-demo.zip`。若沿用此前的阿里云服务器配置，先通过 Workbench 文件管理把它上传到服务器的 `/tmp/`，然后在服务器终端执行：

```bash
sudo tar -czf /tmp/asw-price-backup-$(date +%Y%m%d-%H%M%S).tar.gz -C /var/www/html .
sudo python3 -m zipfile -e /tmp/asw-price-dual-role-demo.zip /var/www/html
curl -I http://127.0.0.1/
```

浏览器访问 `http://47.122.105.169/` 检查新首页。当前服务器上的 HTTPS 入口配置给另一个项目，因此这里需明确使用 `http://`。以上命令会替换 ASW 的首页文件；先核实 `/var/www/html` 仍是 ASW 目录，并保留生成的备份包。

## 推荐演示流程

1. 选择“客户使用入口”，以“上海 → 洛杉矶、40HQ、综合推荐”查询方案。
2. 改成“价格优先”或“时效优先”再次查询，展示排序变化；选一套方案，填写演示客户名称并生成报价单。
3. 在“我的询价”查看报价单，演示打印或另存 PDF。
4. 返回入口，以 `demo` / `ASW2026` 登录管理员界面，展示工作台中新增的报价记录。
5. 导入演示合同并“核对并启用”；调整报价规则后回到客户入口重新询价，展示结果变化。
