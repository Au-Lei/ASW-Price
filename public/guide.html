演示版使用说明

同一个入口，体验客户询价与管理员工作台。所有业务数据均为模拟数据。

客户可以演示什么？

  1. 点击“客户入口”，无需登录；选择港口、柜型、柜量和出货日期。
  2. 选择综合推荐、价格优先或时效优先，点击“查看运输方案”。
  3. 比较船公司、总价、航程、预计开船 / 到港日期与报价有效期；查看方案详情。
  4. 选择方案，填写演示客户名称，生成报价单。
  5. 在“我的报价”搜索、查看记录，打印报价单或通过浏览器另存为 PDF。

演示航线：上海 → 洛杉矶、宁波 → 长滩、深圳 → 汉堡。支持 20GP、40GP、40HQ。

管理员可以演示什么？

点击“管理员登录”：账号 demo，密码 ASW2026。

  • 数据工作台与待办：查看合同、报价统计，处理待核对合同、临期合同及待确认报价。
  • 合同管理：模拟导入、核对并启用合同，切换启用状态。
  • 有效期管理：调整合同到期日，影响询价可用方案。
  • 账号与权限：展示角色、新增演示账号、启用或停用账号。
  • 报价规则与操作记录：调整加价比例、报价有效天数，查看操作日志。

推荐演示顺序（约 3 分钟）

客户询价 → 对比并生成报价单 → 返回入口 → 管理员登录 → 待办中心确认该报价 → 调整报价规则 → 返回客户入口重新询价。

建议先用上海 → 洛杉矶、40HQ、2026-10-18 演示。若无方案，请检查所选日期是否处于已启用、已核对合同的有效期内。

演示边界：数据仅保存在当前浏览器，刷新可保留，不支持跨设备同步或真实客户隔离。合同上传与解析为模拟，不读取真实文件；新增账号不能实际登录；“智能推荐”为模拟规则排序，并非实时 AI 或船期查询。管理员登录不提供真实安全隔离。请勿输入真实合同、敏感客户信息，报价不可用于真实交易或订舱。
